# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.x | Latest release only (pre-1.0; APIs may change) |

## Reporting a vulnerability

Report security issues **privately** to **ekokele707@gmail.com** or via **GitHub private vulnerability reporting** on this repository (enabled).

Include:

- Description of the issue and impact
- Steps to reproduce or a proof of concept
- Affected version or commit
- Your contact for follow-up (optional)

**Target response:** acknowledgement within 7 days. **Coordinated disclosure:** aim to agree on a publication timeline around 90 days where practical.

There is **no bug bounty** at this time.

## Audit status

Sealim has **not** undergone an independent security audit. Do not deploy it for production credential verification until audits and hardening are complete.
